# 私有仓库分发指南

## 方案二：企业私有Maven仓库（推荐企业内部使用）

### 使用Nexus Repository

#### 1. 配置Nexus仓库

在 `pom.xml` 中添加：

```xml
<distributionManagement>
    <repository>
        <id>nexus-releases</id>
        <name>Nexus Release Repository</name>
        <url>http://your-nexus-server:8081/repository/maven-releases/</url>
    </repository>
    <snapshotRepository>
        <id>nexus-snapshots</id>
        <name>Nexus Snapshot Repository</name>
        <url>http://your-nexus-server:8081/repository/maven-snapshots/</url>
    </snapshotRepository>
</distributionManagement>
```

#### 2. Maven设置

`~/.m2/settings.xml`：

```xml
<settings>
    <servers>
        <server>
            <id>nexus-releases</id>
            <username>deployment</username>
            <password>your-password</password>
        </server>
        <server>
            <id>nexus-snapshots</id>
            <username>deployment</username>
            <password>your-password</password>
        </server>
    </servers>
</settings>
```

#### 3. 发布到私有仓库

```bash
mvn clean deploy
```

#### 4. 其他项目使用

在使用项目的 `pom.xml` 中添加仓库配置：

```xml
<repositories>
    <repository>
        <id>nexus-public</id>
        <name>Nexus Public Repository</name>
        <url>http://your-nexus-server:8081/repository/maven-public/</url>
    </repository>
</repositories>

<dependencies>
    <dependency>
        <groupId>com.module</groupId>
        <artifactId>user-assistant-spring-boot-starter</artifactId>
        <version>1.0.0</version>
    </dependency>
</dependencies>
```

## 方案三：GitHub Packages

### 1. 配置GitHub Packages

在 `pom.xml` 中添加：

```xml
<distributionManagement>
    <repository>
        <id>github</id>
        <name>GitHub Packages</name>
        <url>https://maven.pkg.github.com/yourusername/user-assistant-spring-boot-starter</url>
    </repository>
</distributionManagement>
```

### 2. GitHub Token配置

在 `~/.m2/settings.xml` 中：

```xml
<settings>
    <servers>
        <server>
            <id>github</id>
            <username>your-github-username</username>
            <password>your-github-token</password>
        </server>
    </servers>
</settings>
```

### 3. 发布到GitHub

```bash
mvn clean deploy
```

### 4. 使用GitHub Packages

```xml
<repositories>
    <repository>
        <id>github</id>
        <url>https://maven.pkg.github.com/yourusername/user-assistant-spring-boot-starter</url>
    </repository>
</repositories>
```

## 方案四：本地安装（临时方案）

### 1. 生成安装脚本

创建 `install-locally.bat`：

```batch
@echo off
echo 正在安装用户助手Spring Boot Starter到本地Maven仓库...
cd user-assistant-spring-boot-starter
mvn clean install -DskipTests
echo 安装完成！
echo.
echo 在您的项目中添加以下依赖：
echo ^<dependency^>
echo     ^<groupId^>com.module^</groupId^>
echo     ^<artifactId^>user-assistant-spring-boot-starter^</artifactId^>
echo     ^<version^>1.0.0^</version^>
echo ^</dependency^>
pause
```

### 2. 使用说明

1. 将整个项目文件夹发送给需要使用的开发者
2. 开发者运行 `install-locally.bat`
3. 在项目中添加依赖即可使用

## 方案五：JAR包分发

### 1. 创建分发包

```bash
cd user-assistant-spring-boot-starter
mvn clean package -DskipTests

# 创建分发目录
mkdir -p dist
cp target/user-assistant-spring-boot-starter-1.0.0.jar dist/
cp target/user-assistant-spring-boot-starter-1.0.0-sources.jar dist/
cp target/user-assistant-spring-boot-starter-1.0.0-javadoc.jar dist/
```

### 2. 手动安装指南

创建 `README-INSTALL.md`：

```markdown
# 手动安装指南

## 1. 下载JAR包

下载以下文件：
- user-assistant-spring-boot-starter-1.0.0.jar
- user-assistant-spring-boot-starter-1.0.0-sources.jar（可选）

## 2. 安装到本地Maven仓库

```bash
mvn install:install-file \
  -Dfile=user-assistant-spring-boot-starter-1.0.0.jar \
  -DgroupId=com.module \
  -DartifactId=user-assistant-spring-boot-starter \
  -Dversion=1.0.0 \
  -Dpackaging=jar

# 可选：安装源码包
mvn install:install-file \
  -Dfile=user-assistant-spring-boot-starter-1.0.0-sources.jar \
  -DgroupId=com.module \
  -DartifactId=user-assistant-spring-boot-starter \
  -Dversion=1.0.0 \
  -Dpackaging=jar \
  -Dclassifier=sources
```

## 3. 在项目中使用

```xml
<dependency>
    <groupId>com.module</groupId>
    <artifactId>user-assistant-spring-boot-starter</artifactId>
    <version>1.0.0</version>
</dependency>
```
```
