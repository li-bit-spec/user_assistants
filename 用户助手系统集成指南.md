# 用户助手系统集成指南

## 📖 简介

用户助手Spring Boot Starter是一个开箱即用的用户助手系统，提供用户手册管理、技术支持文档、用户反馈等功能。只需几个简单配置，即可在任何Spring Boot项目中快速集成完整的用户助手功能。

## 🚀 快速开始

### 1. 添加Maven依赖

在您的项目 `pom.xml` 中添加依赖：

```xml
<dependency>
    <groupId>io.github.li-bit-spec</groupId>
    <artifactId>user-assistant-spring-boot-starter</artifactId>
    <version>1.0.0</version>
</dependency>

<!-- 数据库驱动（如果使用MySQL） -->
<dependency>
    <groupId>mysql</groupId>
    <artifactId>mysql-connector-java</artifactId>
</dependency>

<!-- 数据库连接池（推荐） -->
<dependency>
    <groupId>com.alibaba</groupId>
    <artifactId>druid-spring-boot-starter</artifactId>
    <version>1.1.13</version>
</dependency>
```

### 2. 启用用户助手功能

在主启动类添加 `@EnableUserAssistant` 注解：

```java
package com.yourcompany.yourproject;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import com.module.starter.annotation.EnableUserAssistant;

@SpringBootApplication
@EnableUserAssistant
public class YourApplication {
    public static void main(String[] args) {
        SpringApplication.run(YourApplication.class, args);
    }
}
```

### 3. 配置数据库连接

在 `application.yml` 中配置：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/your_database?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=GMT%2B8
    username: your_username
    password: your_password
    driver-class-name: com.mysql.cj.jdbc.Driver
    type: com.alibaba.druid.pool.DruidDataSource
    
  # 文件上传配置
  servlet:
    multipart:
      max-file-size: 10MB
      max-request-size: 10MB

# 用户助手模块配置
user-assistant:
  # 文件上传配置
  upload:
    path: ./uploads  # 文件存储路径
    max-file-size: 10MB  # 最大文件大小
    
  # Swagger API文档配置
  swagger:
    enabled: true  # 是否启用Swagger
    title: "用户助手API文档"
    description: "用户助手系统接口说明"
    version: "1.0.0"
    base-package: com.module.controller  # API扫描包路径
```

### 4. 创建数据库表

执行以下SQL创建必要的数据库表：

```sql
-- 用户手册表
CREATE TABLE ass_manual_articles (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(255) NOT NULL COMMENT '标题',
    content LONGTEXT NOT NULL COMMENT '内容',
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户手册文章表';

-- 技术支持文章表
CREATE TABLE ass_support_articles (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(255) NOT NULL COMMENT '标题',
    content LONGTEXT NOT NULL COMMENT '内容',
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='技术支持文章表';

-- 用户反馈表
CREATE TABLE ass_feedbacks (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    content TEXT NOT NULL COMMENT '反馈内容',
    contact_info VARCHAR(255) COMMENT '联系方式',
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户反馈表';

-- 反馈图片表
CREATE TABLE ass_feedback_images (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    feedback_id BIGINT NOT NULL COMMENT '反馈ID',
    image_url VARCHAR(500) NOT NULL COMMENT '图片URL',
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    FOREIGN KEY (feedback_id) REFERENCES ass_feedbacks(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='反馈图片表';
```

## 🌐 访问系统

启动应用后，您可以通过以下方式访问用户助手系统：

### 前端界面
- **主页**：http://localhost:8080
- **用户手册**：http://localhost:8080/#/manual
- **技术支持**：http://localhost:8080/#/support  
- **用户反馈**：http://localhost:8080/#/feedback

### API文档
- **Swagger UI**：http://localhost:8080/swagger-ui.html
- **API文档JSON**：http://localhost:8080/v2/api-docs

### REST API端点

#### 用户手册管理
```
GET    /api/manual/articles         # 获取手册列表
POST   /api/manual/articles         # 创建手册
PUT    /api/manual/articles/{id}    # 更新手册
DELETE /api/manual/articles/{id}    # 删除手册
GET    /api/manual/articles/{id}    # 获取手册详情
```

#### 技术支持管理
```
GET    /api/support/articles        # 获取支持文档列表
POST   /api/support/articles        # 创建支持文档
PUT    /api/support/articles/{id}   # 更新支持文档
DELETE /api/support/articles/{id}   # 删除支持文档
GET    /api/support/articles/{id}   # 获取支持文档详情
```

#### 用户反馈管理
```
GET    /api/feedback               # 获取反馈列表
POST   /api/feedback               # 提交反馈
DELETE /api/feedback/{id}          # 删除反馈
GET    /api/feedback/{id}          # 获取反馈详情
```

#### 文件上传
```
POST   /api/upload                 # 上传文件
```

## ⚙️ 高级配置

### 自定义配置

您可以通过配置文件自定义各种参数：

```yaml
user-assistant:
  # 文件上传配置
  upload:
    path: /data/uploads              # 自定义文件存储路径
    max-file-size: 20MB             # 自定义最大文件大小
    allowed-types:                  # 允许的文件类型
      - image/jpeg
      - image/png
      - image/gif
      - application/pdf
    
  # 前端配置
  frontend:
    title: "我的用户助手系统"       # 自定义系统标题
    
  # Swagger配置
  swagger:
    enabled: true
    title: "我的API文档"
    description: "项目API接口文档"
    version: "2.0.0"
    contact:
      name: "技术支持"
      email: "support@yourcompany.com"
```

### 数据库配置选项

支持多种数据库：

```yaml
# MySQL配置示例
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/database
    username: username
    password: password
    driver-class-name: com.mysql.cj.jdbc.Driver

```

## 🔧 自定义扩展

### 自定义Controller

如果需要扩展功能，可以创建自己的Controller：

```java
@RestController
@RequestMapping("/api/custom")
@Api(tags = "自定义接口")
public class CustomController {
    
    @Autowired
    private AssManualArticleService manualService;
    
    @GetMapping("/stats")
    @ApiOperation("获取统计信息")
    public ResponseEntity<Map<String, Object>> getStats() {
        Map<String, Object> stats = new HashMap<>();
        stats.put("manualCount", manualService.count());
        // 添加更多统计信息
        return ResponseEntity.ok(stats);
    }
}
```

### 自定义配置类

```java
@Configuration
@ConditionalOnProperty(prefix = "user-assistant", name = "enabled", havingValue = "true", matchIfMissing = true)
public class CustomUserAssistantConfig {
    
    @Bean
    @ConditionalOnMissingBean
    public CustomService customService() {
        return new CustomServiceImpl();
    }
}
```

## 🛠️ 故障排除

### 常见问题

1. **无法访问前端页面**
   - 检查是否添加了 `@EnableUserAssistant` 注解
   - 确认端口8080没有被其他应用占用

2. **数据库连接失败**
   - 检查数据库连接配置
   - 确认数据库服务已启动
   - 验证用户名密码正确

3. **文件上传失败**
   - 检查文件存储路径是否有写权限
   - 确认文件大小没有超过限制

4. **Swagger无法访问**
   - 确认 `user-assistant.swagger.enabled=true`
   - 检查是否有安全配置阻止访问

### 日志配置

```yaml
logging:
  level:
    com.module: DEBUG
    org.springframework.web: DEBUG
```
